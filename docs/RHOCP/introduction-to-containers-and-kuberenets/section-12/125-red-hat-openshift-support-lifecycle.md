Red Hat OpenShift Container Platform follows a release lifecycle policy with regular minor releases. Red Hat designates even-numbered minor releases (such as 4.18, 4.20, and 4.22) as Extended Update Support (EUS) releases, which carry a longer support window than odd-numbered releases.

Starting from OpenShift Container Platform 4.14, the EUS phase for even-numbered releases provides a total lifecycle of 24 months on all supported architectures. An optional 12-month add-on can extend the total support to 36 months, which provides stability for mission-critical production environments.
