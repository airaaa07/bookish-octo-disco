Public cloud providers, such as Amazon, Microsoft, IBM, and Google, each provide quick access to an on-demand Red Hat OpenShift deployment. These fully managed application platforms offer quick access to a cluster on infrastructure that you can rely on from a Red Hat trusted cloud provider.

When using managed services, more responsibilities are delegated to Red Hat and to the cloud provider. Because the installation process integrates with the cloud provider, the managed service creates and manages all necessary cloud resources. For example, the Red Hat Site Reliability Engineering teams update the clusters and remedy any update issues (although you still participate in scheduling the updates). Each managed edition documents the responsibilities for customers, Red Hat, and the cloud provider.

Additionally, to assist in managing clusters, the Red Hat Lightspeed advisor service is available from the Red Hat Hybrid Cloud Console. Lightspeed advisor helps administrators to identify and remediate cluster issues by analyzing data that the Insights Operator provides. The data from the operator is uploaded to the Red Hat Hybrid Cloud Console, where you further inspect the recommendations and their impact on the cluster.
