# Red Hat OpenShift Container Platform (RHOCP)

## Overview

Red Hat OpenShift Container Platform (RHOCP) is a complete platform for running applications across clusters of servers. It is built on existing technologies such as **containers** and **Kubernetes**.

### Containers

Containers package applications along with their dependencies, allowing them to run in different environments that have a compatible container runtime.

### Kubernetes

Kubernetes provides features to build and manage clusters of servers that run containerized applications. However, Kubernetes is not designed to provide a complete application platform on its own. Instead, it provides extension points that system administrators and developers can use to extend its functionality.

### OpenShift

OpenShift builds on Kubernetes and extends its capabilities to provide a more complete application platform. It uses Kubernetes extension points and additional platform features to simplify the deployment, management, and operation of containerized applications.

## Key Takeaway

- **Containers:** Package applications and their dependencies.
- **Kubernetes:** Orchestrates containerized applications across a cluster.
- **OpenShift:** Extends Kubernetes to provide a more complete platform for running and managing applications.
